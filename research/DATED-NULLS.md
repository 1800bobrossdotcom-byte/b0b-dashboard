# DATED NULLS — the watch list

Internal (research/ is never served). A **dated null** is a published negative
finding: "as of DATE, X has not happened." It is true only on its date. Left
unattended it silently becomes a false statement — the report keeps asserting a
negative the world has already resolved.

**This file exists because that failure actually occurred.** On 2026-08-24 the
report asserted the USVI special-master reports were unsealed-pending "no
ruling," when the court had in fact denied access three times, most recently
seven months earlier (29 Jan 2026). The upstream research had reported "no
citable ruling found" — a statement about *the search*, not about the world —
and it was published as though it were a statement about the world. That is the
same non-diagnostic-evidence error the report corrects elsewhere. Absence of a
found ruling is not absence of a ruling.

Checked weekly by a scheduled Routine. Rule: **report only on change**, and
**hold changes for the user** rather than auto-publishing.

## Standing method note
When a check returns "could not find X," record it as **"not found in this
search"** — never as "X did not happen." Only a source that affirmatively
establishes a negative supports a published null. If the discriminating record
is unreachable (paywalled docket, sealed file), say so and mark confidence low.
